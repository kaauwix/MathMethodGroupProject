# MathMethodGroupProject
# Документация

## 1. Общая информация
- `PrimalSimplex.py` — прямой симплекс-метод.
- `DualSimplex.py` — двойственный симплекс-метод.
- `AuxiliaryFun.py` — общие вспомогательные функции, используемые обоими методами.


## 2. PrimalSimplex.py

### Прямой симплекс-метод
**Входные данные:**
- `c` — коэффициенты целевой функции;
- `A` — матрица коэффициентов ограничений;
- `b` — вектор свободных членов;
- `signs` — знаки ограничений (`<=`, `>=`, `=`);
- `objective` — направление оптимизации (`"max"` или `"min"`).

**Результат:** словарь с результатами решения, содержащий статус, сообщение, найденные значения переменных, значение целевой функции и этапы вычислений.


## 3. DualSimplex.py

### Двойственный симплекс-метод
**Основная функция:** `dual_simplex(c, A, b, signs, objective="max", max_iterations=1000)`
Метод применяется, когда начальное базисное решение не является допустимым по свободным членам, но сохраняется двойственная допустимость (все оценки неотрицательны).

**Входные параметры:**
- `c` — коэффициенты целевой функции;
- `A` — матрица коэффициентов ограничений;
- `b` — вектор свободных членов;
- `signs` — знаки ограничений (`<=`, `>=`, `=`);
- `objective` — направление оптимизации (`"max"` или `"min"`);
- `max_iterations` — максимальное количество итераций (по умолчанию 1000).

**Основные этапы работы:**
1. Приведение исходной задачи к стандартному виду.
2. Формирование начальной симплексной таблицы и поиск базиса.
3. Проверка знаков свободных членов и оценок.
4. При необходимости — попытка замены переменных `x_j = M_j - y_j`.
5. Выбор разрешающей строки и столбца.
6. Пересчёт симплексной таблицы.
7. Проверка условий оптимальности.
8. Восстановление исходных переменных после замены, если она выполнялась.

**Возвращаемое значение:** словарь с результатами решения:
- `status` — статус завершения алгоритма;
- `message` — сообщение о результате;
- `solution` — значения исходных переменных;
- `objective_value` — значение целевой функции;
- `steps` — последовательность этапов решения;
- `tableau` — итоговая симплексная таблица;
- `basis` — итоговый базис;
- `deltas` — итоговые оценки;
- `problem` — данные нормализованной задачи.


## 4. AuxiliaryFun.py
Модуль содержит общие функции, используемые симплексными методами.

### Константа
**`EPSILON`** Допуск для сравнения чисел с нулём при вычислениях с плавающей точкой.

### Сохранение этапов решения
**`add_text_step(steps, title, description, data=None)`** Добавляет текстовый этап решения.
Принимает:
- `steps` — список этапов;
- `title` — название этапа;
- `description` — описание действий;
- `data` — дополнительные данные (необязательно).

Возвращает: ничего. Изменяет переданный список `steps`.
**`add_table_step(steps, tableau, basis, variable_names, c, description, pivot=None)`**
Сохраняет состояние симплексной таблицы.
Принимает:
- `steps` — список этапов;
- `tableau` — симплексная таблица;
- `basis` — индексы базисных переменных;
- `variable_names` — названия переменных;
- `c` — коэффициенты целевой функции;
- `description` — описание этапа;
- `pivot` — информация о разрешающем элементе (необязательно).
Возвращает: ничего. Добавляет таблицу и рассчитанные показатели в `steps`.

### Проверка и преобразование задачи
**`validate_problem(c, A, b, signs, objective="max")`**
Проверяет корректность исходных данных: размеры матрицы, количество ограничений, знаки и числовые значения.
Возвращает:
- количество исходных переменных;
- список нормализованных знаков ограничений.
При некорректных данных вызывает `ValueError`.

**`normalize_problem(c, A, b, signs, objective="max")`**
Приводит задачу к нормализованному виду:
- преобразует задачу на минимум в задачу на максимум;
- приводит ограничения `>=` к виду `<=`;
- добавляет дополнительные переменные;
- сохраняет исходные данные и этапы преобразования.
Возвращает словарь с коэффициентами, матрицей ограничений, свободными членами, названиями переменных и исходными данными задачи.

### Работа с базисом и оценками

**`find_initial_basis(A)`**
Ищет начальный единичный базис в матрице ограничений
Возвращает список индексов базисных переменных или `None`, если базис сформировать не удалось.

**`calculate_deltas(tableau, c, basis)`**
Вычисляет оценки `Delta_j = Z_j - C_j` для всех переменных.
Возвращает список оценок.

**`determine_method(tableau, c, basis)`**
Определяет рекомендуемый метод решения на основе знаков свободных членов и оценок.
Возвращает словарь с названием метода и поясняющим сообщением.

### Операции с симплексной таблицей

**`pivot_operation(tableau, pivot_row, pivot_column)`**
Выполняет пересчёт симплексной таблицы относительно разрешающего элемента.

Принимает:
- `tableau` — симплексная таблица;
- `pivot_row` — индекс разрешающей строки;
- `pivot_column` — индекс разрешающего столбца.

Возвращает: ничего. Изменяет переданную таблицу.

**`build_tableau(A, b)`**
Формирует симплексную таблицу из матрицы ограничений и вектора свободных членов.
Возвращает готовую таблицу с добавленным столбцом свободных членов.

**`recover_solution(tableau, basis, variable_count)`**
Восстанавливает значения переменных по итоговой таблице и базису.
Возвращает вектор найденного решения.

**`calculate_objective(c, solution)`**
Вычисляет значение целевой функции по её коэффициентам и найденному решению.
Возвращает числовое значение целевой функции.

**`get_tableau_state(tableau, basis, c)`**
Вычисляет основные показатели текущей симплексной таблицы: свободные члены, оценки, коэффициенты базисных переменных и значения `Z_j`.
Возвращает словарь с рассчитанными показателями.

### Формирование результата
**`make_result(status, message, steps, solution=None, objective_value=None, tableau=None, basis=None, deltas=None, problem=None)`**

Формирует единый формат результата работы алгоритма.
Возвращает словарь с информацией о статусе решения, сообщением, найденным решением, значением целевой функции, этапами и итоговыми данными симплексной таблицы.

### Замена переменных
**`prepare_variable_substitution(c, A, b, signs)`**

Выполняет подготовку замены переменных вида `x_j = M_j - y_j`.
Ищет конечные верхние границы исходных переменных, преобразует коэффициенты целевой функции и ограничений, добавляет ограничения `y_j <= M_j`.
Возвращает словарь с преобразованной задачей и найденными границами либо сообщение об ошибке, если выполнить замену невозможно.


## 5. MIB.py (Метод искусственного базиса)

### Метод искусственного базиса
**Основная функция:** `artificial_basis_simplex(c, A, b, signs, objective="max", max_iterations=1000)`
Метод применяется, когда в матрице ограничений отсутствует начальный единичный базис (нет готового опорного плана). В этом случае вводятся искусственные переменные, и решается вспомогательная задача.

**Входные параметры:**
- `c` — коэффициенты целевой функции;
- `A` — матрица коэффициентов ограничений;
- `b` — вектор свободных членов;
- `signs` — знаки ограничений (`<=`, `>=`, `=`);
- `objective` — направление оптимизации (`"max"` или `"min"`);
- `max_iterations` — максимальное количество итераций (по умолчанию 1000).

**Основные этапы работы:**
1. Приведение задачи к канонической форме (через `normalize_problem`).
2. Проверка наличия единичного базиса. Если он есть, возвращается статус `basis_exists` (задача решается прямым симплексом).
3. Для строк без единичного столбца вводятся искусственные переменные `w_i`. Строится вспомогательная функция `F = -sum(w_i) -> max`.
4. Решение вспомогательной задачи обычным симплекс-методом (поиск разрешающего элемента, жордановы преобразования).
5. Анализ результата:
   - если `max F < 0` — система ограничений противоречива (статус `infeasible`);
   - если `max F = 0` — искусственные переменные выводятся из базиса (или удаляются нулевые строки).
6. Удаление столбцов искусственных переменных из таблицы.
7. Пересчёт оценок по исходной целевой функции и продолжение решения прямым симплекс-методом до получения оптимума.

**Возвращаемое значение:** словарь в формате `make_result` (аналогично прямым методам).


## 6. optimal.py (Проверка оптимальности)

### Проверка плана на оптимальность (2-я теорема двойственности)
**Основная функция:** `check_optimality(c, A, b, x, signs, tolerance=1e-7)`
Проверяет заданный план `x` на оптимальность, используя условия дополняющей нежёсткости (2-я теорема двойственности). Работает для задач вида `f=(c,x)->max`.

**Входные параметры:**
- `c` — коэффициенты целевой функции;
- `A` — матрица коэффициентов ограничений;
- `b` — вектор свободных членов;
- `x` — проверяемый план (список значений);
- `signs` — знаки ограничений (`<=`, `>=`, `=`);
- `tolerance` — допуск для сравнения чисел с нулём (по умолчанию 1e-7).

**Основные этапы работы:**
1. Приведение всех ограничений к виду `<=` (равенства разбиваются на два неравенства).
2. Проверка допустимости плана `x` (условия неотрицательности и соблюдение ограничений). Если план недопустим — возвращается статус `not_feasible`.
3. Построение множеств `J_x` (индексы переменных, где `x_j > 0`) и `I_x` (индексы ограничений, выполняющихся как строгое неравенство).
4. Формирование системы уравнений относительно двойственных переменных `y`: `(A^j, y) = c_j` для `j` из `J_x` и `y_i = 0` для `i` из `I_x`.
5. Проверка совместности системы (через ранг матрицы).
6. Поиск решения `y` и проверка условий двойственной задачи: `y >= 0` и `A^T y >= c`.

**Возвращаемое значение:** словарь с результатами проверки:
- `status` — статус (`optimal`, `not_optimal`, `not_feasible`, `error`);
- `message` — текстовое пояснение результата;
- `y` — найденный вектор двойственных оценок (если план оптимален или найден кандидат);
- `J_x`, `I_x` — построенные множества индексов (если план оптимален).
